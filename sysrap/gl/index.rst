photon record presentation
---------------------------

rec_flying_point
    literally a flying point representing the photon position as simulation time is changed

rec_flying_point_persist
    like rec_flying_point but step points are persisted after time has passed them by

rec_flying_vec
    based on rec_flying_point but with a short vector instead of a point - time "length" of the
    vec from Auxil.x uniform that can be set by SGLM__init_auxil envvar

rec_line_strip
    long lines showing photon paths - needs low stats to be useful
